# 面向数学家的使用说明

这是论文的可复核计算附件：它展示实际求和、单项贡献和精确证书。**形式单箭头图的残差可能不为零；经典情形的整体结论由 linking-number 恒等式给出。**

## 从哪里开始

1. 解压后打开 `reports/index.html` 选择语言，无需安装。中文版为 `reports/zh/index.html`，英文版为 `reports/en/index.html`。
2. 先读“读图与证书指南”，认识实线弧、虚线补弧和三个不同的编号。
3. 打开 cube `(1,1)` 的 β₁ 报告，其中有 case 16 与 case 18 的对照解释。
4. 查看“恒等式证书”，展开“全部系数”，检查残差与几何表达式怎样逐项相等。

需要选择其他情况时，在仓库根目录运行：

```sh
python -m pip install .
python -m cocycle serve --lang zh
```

浏览器打开 `http://127.0.0.1:8765`。也可安装 notebook 依赖后打开 `Explore.ipynb`。

## 圆怎么读

从顶部基点 ∞ 出发，**逆时针**读取。圆内的弦是 Gauss 箭头；弦之间的交点不代表额外的结交叉。

| 方程 | 实线核心端点块 | 每块的端点数 | 虚线补区间 | ∞ 左侧 / 右侧 |
|---|---:|---|---|---|
| Cube | 3 | rotation 0: 2,3,3；rotation 1: 3,3,2；rotation 2: 3,2,3 | B_0,…,B_3 | B_0 / B_3 |
| Tetrahedron | 4 | 3,3,3,3 | B_0,…,B_4 | B_0 / B_4 |
| R3–R3 commute | 6 | 2,2,2,2,2,2 | B_0,…,B_6，仅作读图编号 | B_0 / B_6 |

- **实线圆弧**连接同一个固定核心端点块中的端点；不要按当前某一个 R3 三角形重新分块。
- **虚线圆弧**是可插入外部箭头端点的补区间。即使已经插入了外部端点，它仍画虚线。
- 核心端点画实心点；外部端点画空心点。
- 红色弦属于当前 R3；蓝色弦是该公式项选中的贡献箭头。
- 箭头从下穿端指向上穿端。弦标签 `5:−` 表示交叉编号 5、交叉符号 −1；圆外小数字是从 0 开始的矩阵行号。
- 基点把它所在的圆周间隙分成前后两个区间，因此补区间数比实线块数多一个。
- Commute 的补弧编号只辅助读图，不表示本包额外做了 commute 外部箭头枚举。

**两套区间不要混淆：**报告中的 B 是整个局部核心的补区间；β 公式数组第四列里的 0–3 是某一个 R3 三角形的补区间编号。两者用途不同。

## X[a,b,d] 是什么

`X[a,b,d]` 表示一类外部箭头的**交叉符号之和**。

- `a,b`：两个端点分别所在的补区间 B_a、B_b，且 a ≤ b。下标 b 是拉丁字母，不是 β。
- `d`：从 ∞ 出发先遇到的端点的方向。`+1` 是箭头端／上穿端；`−1` 是箭尾端／下穿端。
- `d` **不是交叉正负号**。满足位置和方向条件后，每根正交叉箭头向 X 贡献 +1，负交叉箭头贡献 −1。
- 若 a=b，则按同一补区间内两个端点的先后确定 d。
- 表达式的常数项是核心交叉的带符号贡献，不是核心箭头根数。

例如 `X[1,2,−1]` 统计从 B_1 指向 B_2 的外部箭头。若这种箭头有三根正交叉、两根负交叉，则 X=3−2=1。

## residual increment 是什么

`ΔR = R(核心＋一根外部箭头) − R(只有核心)`。

增量描述的是**所选 β 对应的局部方程残差**的变化，不是 β 本身的定义变化。标题只显示当前所选 β，不再显示未标明顺序的三元素列表。展开后同时列出核心值、增量和完整单箭头图的残差。β₃ 的最终数值在模二下计算，整数提升另行显示。

每个 outside-arrow case 都是独立输入。程序不会将不同 case 的残差相加来宣称它们全部通过。

## cube case 16 / 18：为什么一个是 −1，另一个是 +1

以下编号专指 cube `template=1, rotation=1`。

| Case | 唯一外部箭头 | X[1,2,−1] | X[1,2,+1] | 非零项 | β₁ 残差 |
|---|---|---:|---:|---|---:|
| 16 | B_1 → B_2，负交叉 | −1 | 0 | p2 第 6 项，选箭头 [1,5] | −1 |
| 18 | B_2 → B_1，负交叉 | 0 | −1 | p1 第 10 项，选箭头 [3,5] | +1 |

核心残差为零，所以这里增量恰好等于完整残差。p2 的显示值已经乘了路径方向 −1；标题中的 coorientation +1 是另一个因子，不能把两者混为一谈，也不要再给 p2 的显示值取负。

残差表达式是 `R = X[1,2,−1] − X[1,2,+1]`。如果**同一张完整图**里两类负箭头各有一根，它们的增量确实相消。但这不证明只加这两根就能得到经典图，也不允许把独立测试输入相加作为证明。

平滑交叉 2、3 后，报告中的 component 1、2 分别记作 A、B。Case 16 中只有交叉 5 连接 A、B，且 A 在 B 上方、符号为负；case 18 则相反。这种孤立的单交叉关系不能是经典两分量图。

## 程序如何验证整体消去

1. 实际计算 R3 事件，获得残差多项式 R 的每个系数。
2. 独立平滑核心交叉，追踪分量，构造 `H = Σ sign(A over B) − Σ sign(B over A)`。
3. 用精确运算逐个比较系数，验证 `R = Σ c_i H_i`，包括常数项。
4. 经典链环的两个带符号交叉和都计算同一个 linking number，因此 H_i=0，从而 R=0。

Cube `(1,1)` 的 β₁ 证书就是 `R=H7`。报告列出全部 21 个系数的比较；tetra 列出全部 31 个系数。这里没有要求逐根配对，也没有抹去形式虚拟图上非零的原始残差。

零／单外部箭头检查足够的依据，是文档中的 outside-only 项配对消去和剩余项的仿射线性归约。`replay` 核对存储的几何证书；`verify` 才会重新计算原始残差及全部方程。

## 编号与范围

- tetrahedron：s=1,…,24，与原 notebook 一致，template=48(s−1)。
- cube：template=0,…,47，rotation=0,1,2。
- commute：(u,v,a)，u,v=0,…,47，a=0,…,9。`--positive` 保留原六类型约定。
- 公式 Term 编号从 1 开始，outside-arrow case 编号从 0 开始。
- v₄,₁=J15，v₄,₂=E34，不是旧 notebook 中的 primitive 归一化。
- Rolling 显式反转原 notebook 路径方向；β 系数没有改动。
- Half rolling 使用实际周期性、零 framing 的输入图，不是把模二结果除以二。
- β₃ 最小组合阶数证明不包含在本包中；R1–R3、R2–R3、wandering cusp 也没有作为额外完整枚举宣称通过。
- 有限 loop 比较是论文理论论证的计算输入，不代替一般公式的理论证明。

## 重算与重新生成网页

在仓库根目录运行：

```sh
python -m unittest discover -s tests -v
python -m cocycle verify --output new-results
python -m cocycle replay --certificates new-results/local-certificates.json
python -m cocycle.examples
```

最后一个命令使用随包证书、公式和示例路径记录重新生成示例网页。命令行、浏览器、notebook 使用同一套报告绘制程序。


## 1.2.0：独立语言版本与箭头可读性

所有报告均分别生成英文版和中文版，解释段落、表头、按钮和图注对应。中文版保留 R3、Gauss、cocycle、rolling 等专业词汇；公式、变量名及原始 JSON 字段共用，不翻译成另一套标识符。

灰色箭头与彩色箭头使用相同的固定大小箭头头部，不再随线条粗细缩小；箭头尖端与端点圆点之间留有间距。箭头依然表示下穿端指向上穿端，不改变数学方向。

命令行的 `show`、`loop`、`serve` 都支持 `--lang en` 和 `--lang zh`。Notebook 的 Language 下拉框可选择报告语言。两种静态报告目录都有通往相应另一语言页面的链接。
