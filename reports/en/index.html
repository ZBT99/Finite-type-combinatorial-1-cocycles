Scope

Exact classical certificates cover 24 positive tetrahedron cores and 144 cube cores. All 23,040 signed R3–R3 meridian sums vanish; 136 loop comparisons agree. Raw virtual residuals are retained. β₃ minimal-order proof is excluded; general loop formulas also use the theoretical arguments in the paper.

To select other cases, run python -m cocycle serve --lang en and open http://127.0.0.1:8765. Rebuild both editions with python -m cocycle.examples.
