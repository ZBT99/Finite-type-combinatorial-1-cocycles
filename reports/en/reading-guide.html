Reading diagrams and certificates

Read the arc labels first, then arrow directions and crossing signs, and finally the residual and its certificate.

1. The three core partitions

Solid circle arcs connect endpoints in a fixed core block. Dashed arcs are gaps where outside endpoints may be inserted. Filled dots are core endpoints; hollow dots are outside. Gaps stay dashed after insertion. The partition belongs to the whole core, not just the current R3 triangle.

Read counterclockwise from ∞ at the top: B0 lies to its left, and the last B lies to its right. The basepoint splits one circular gap into two based intervals, so m core blocks give m+1 gap labels.

Cube · 3 solid blocks

Endpoints per core block: [2, 3, 3]. Dashed gaps: B0–B3.

Tetrahedron · 4 solid blocks

Endpoints per core block: [3, 3, 3, 3]. Dashed gaps: B0–B4.

R3–R3 commute · 6 solid blocks

Endpoints per core block: [2, 2, 2, 2, 2, 2]. Dashed gaps: B0–B6.

Commute labels B0–B6 are only a reading aid; no additional commute outside-arrow enumeration is claimed. The four intervals in an individual R3 formula array are a different convention from these whole-core B labels.

2. Arrowheads and endpoints

Arrows point from underpass to overpass. Their arrowheads have a fixed display size, independent of shaft thickness, and stop before the endpoint dot. Red marks the current R3; blue marks selected contributing arrows; gray marks the remaining arrows. A label such as 5:− gives crossing number and sign. Intersecting chords are not new knot crossings.

3. What X[a,b,d] counts

a,b are gap numbers with a ≤ b, not crossing labels. At the endpoint encountered first from ∞, d=+1 means head/overpass and d=−1 means tail/underpass. When a=b, use the order within that gap. d is not the crossing sign. Each matching positive crossing adds +1 to X; each negative crossing adds −1.

Thus X[1,2,−1] sums signs of arrows from B1 to B2. In X[1,2,−1]=−1, the −1 inside brackets specifies direction; the −1 after the equals sign is the signed count. The subscript b in Bb is a Latin letter. The constant term is a signed core contribution, not a count of core arrows.

4. Residual increment

ΔR = R(core + one outside arrow) − R(core)

The heading shows only the selected cocycle. Core residual plus increment equals the full one-arrow residual. β₃ is reduced modulo two, with its integer lift retained. Event values already include coorientation and path sign; do not apply these factors again.

5. Cube cases 16 and 18

For cube (1,1), case 16 has a negative arrow B1 → B2: term 6 at p2 gives −1. Case 18 has a negative arrow in the opposite direction: term 10 at p1 gives +1. Here the core residual is zero.

R = X[1,2,−1] − X[1,2,+1]

One arrow of each type in a single complete diagram would cancel these increments. This is not a proof by summing independent test cases, and it does not construct a classical completion. Smoothing crossings 2,3 makes crossing 5 the only crossing between components 1,2 in either isolated one-arrow case; this cannot be a classical two-component diagram.

6. How the certificate proves classical cancellation

  1. Compute R from actual R3 sums, including the constant and every outside-arrow coefficient.
  2. Independently smooth core crossings, trace components, and construct linking identities H from signed over/under counts.
  3. Check every coefficient exactly to verify R = Σ cᵢHᵢ.

For classical links, Hᵢ=0 because the over- and under-crossing sums calculate the same linking number. Hence R=0 for classical completions. Formal virtual cases can have nonzero raw residuals. No unique one-to-one arrow matching is asserted. Arithmetic is exact over Q for β₁,β₂ and over F₂ for β₃.
